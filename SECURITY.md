# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/tommyp1200-lab/ascend-vanta/security/advisories/new).

Do not open a public issue containing exploit details, credentials, personal data, or sensitive infrastructure information.

Include the affected URL or component, reproduction steps, expected impact, and any relevant request or browser details. Avoid destructive testing, denial-of-service activity, credential attacks, automated high-volume scanning, or accessing data that does not belong to you.

Reports will be acknowledged as soon as practical. Confirmed issues will be prioritized by severity, fixed on a private branch where appropriate, and disclosed only after remediation.

## Supported version

Security updates apply to the version currently deployed at `https://www.ascendvanta.com`.
