# Hero Rock Field

The rock layer is intentionally sparse, with its original hero-rock scale reduced by 50% after visual tuning. It uses three procedurally distorted faceted geometries, one shared graphite physical material, deterministic instance placement, and tiered counts from 4 to 18. No moon, particle ring, card UI, copy, or controls from the supplied reference component are included.

The formation leaves the center clear for the AV mark while distributing rocks across three seeded orbital planes. Those coordinates are locked together under one tilted parent rig, so the complete formation makes a synchronized 360-degree orbit around the logo with real front-to-back travel and no independent orbital drift. The parent receives restrained cursor parallax and reduced-motion scaling, and uses the existing studio environment and key lights so the silhouettes read as solid volume rather than flat sprites.

Rock orientation is fixed inside the formation so every instance moves as one coherent three-dimensional system. A full orbit takes 42 seconds at standard motion speed; the tuned rock size and sparse tier counts remain unchanged.
